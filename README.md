# Chittransh Gautam — Creator Portfolio

A responsive creator portfolio for Chittransh Gautam, featuring creator introduction, mimicry and entertainment focus, creator journey metrics, social profiles and collaboration contact.

## Publish with GitHub Pages
1. Open the repository: https://github.com/chittranshgautam/chittransh-gautam-portfolio
2. Choose **Add file → Upload files**.
3. Upload and replace the project files from this folder, keeping the `assets` folder structure.
4. Commit changes to the `main` branch.
5. GitHub Pages will redeploy automatically.
